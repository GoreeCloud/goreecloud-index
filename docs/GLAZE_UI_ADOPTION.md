## Historical source boundary

Authoritative Index main previously contained a generic Android dynamic-Material theme while its Platform manifest described pre-reset Glaze `2.1.0` source targeting and an obsolete `1.1.0` required target. Draft PR #16 later explored a V1.1 repository-owned theme on an older main revision. Those records remain historical Development provenance; neither is current V1.3 acceptance.

The current V1.3 candidate is rebuilt from current main after Platform Contract v0.2 integration. It does not merge the stale V1.1 branch or reinterpret its evidence.

## Native mapping

Index uses native Jetpack Compose / Material 3 controls while owning its application theme and interaction semantics.

The repository-local V1.3 mapping:

- replaces generic Android dynamic color with deterministic Index-owned schemes;
- keeps neutral structure dominant and uses Deep Teal as primary identity with restrained Soft Amber secondary counter-light;
- provides explicit Light, Dark, and Deep Dark source modes;
- uses 16 / 24 / 32 dp control/container/hero shape hierarchy;
- preserves 48dp ordinary and 56dp Touch Assistance target floors in the source contract;
- keeps nested backdrop blur disabled;
- does not require remote or environmental color derivation;
- records exact current Stable source authority and rollback baseline in a unit-tested native contract;
- leaves adaptive navigation, dynamic personalization, contextual intelligence, user-facing Deep Dark selection, and other V1.3 features unclaimed until they are actually implemented and accepted for Index.

System dark mode selects the Dark scheme. Deep Dark is implemented as an explicit callable source mode but is not yet exposed as a supported user preference.
